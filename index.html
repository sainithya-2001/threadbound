PRIVACY & AI ANALYSIS

Your chat stays here unless you opt in.

Off by default. When enabled, THREADBOUND sends only message text from the five-minute pre-raid and three-minute post-raid windows (up to 160 messages per window, 500 characters per message) to OpenAI for conversation analysis. Twitch chatter names, IDs, badges, and other identity fields are discarded before the request. THREADBOUND keeps raw chat in memory only and does not store it in SQLite. OpenAI processes the submitted text; turning consent off blocks future requests and cancels a pending request where possible, but cannot recall content already sent.

Twitch raid detection and bounded chat capture can keep working while AI analysis is off. Turn consent on before a raid to create a context draft.
